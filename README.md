# Environment-Explanation
The bike-sharing trip data was retrieved from the competition platform (https://www.biendata.xyz/, provided by Mobike). The greenspace data was derived from the WorldCover dataset (https://esa-worldcover.org/en). Air pollution data is available through CNEMC (https://www.cnemc.cn/). Weather condition data was sourced from CMDC (https://data.cma.cn).
