13变量模型、SHAP和PDP：独立Python代码包

一、文件分工
train_ols.py：OLS。
train_rf.py：Random Forest。
train_catboost.py：CatBoost。
train_lightgbm.py：LightGBM。
train_xgboost.py：XGBoost，默认使用原代码的三组候选网格。
train_lstm.py：LSTM，固定一个配置，连续24小时×13变量输入，五折评价。
shap_analysis.py：SHAP总结图（mean |SHAP|条形背景与散点组合），以及全部训练观测的SHAP数值和排序。
shap_dependence.py：一维SHAP依赖散点图，每页最多6个面板。
pdp_1d.py：真正的一维PDP，通过替换变量后平均模型预测得到。
pdp_2d.py：二维PDP 3×3图，按训练SHAP排序选择前三个变量，各与紧随其后的三个变量配对。
plot_predictions.py：六种模型四个目标的4×6实际值—预测值图，使用共享坐标名称和一个图例。
prepare_data.py：准备共同建模数据和冻结的时间划分。
summarize_results.py：独立从逐行预测重算精度，汇总全部模型，不强制XGBoost排名。
run_all.py：分阶段或完整运行入口。
import_saved_results.py：导入此前已经完成的13变量模型和预测，随后可以只运行解释代码。
self_check.py：无真实模型训练的数据、时间划分和计算语义检查。
config.py、runtime.py、data_protocol.py、training_common.py、explanation_common.py、plot_utils.py：共用实现，避免模型间划分和输入不一致。请保留整个目录结构，各入口文件依赖这些共用模块。

二、输入与目标
严格保留13个输入：Day of Week、Hour of Day、O3、PM2.5、PM10、SO2、NO2、CO、Temperature、Wind Speed、Pressure、Humidity、Precipitation。
不使用ordercount、Trip Volume、Ln_Trip Volume、Travel Distance及其替代编码。本仓库不随代码提供观测CSV，请将本地小时表放到data/GE.csv；格式见data/README.md。生成的prepared_model_data.csv只含13个输入、4个结果变量和行号/时间戳元数据，模型X只能从13列白名单构造。
四个目标为SGE、EGE、GiniStart、GiniEnd；所有训练文件默认分别运行四个目标，也可用--targets EGE等指定目标。一个目标训练一个模型，不把四个目标混成多输出回归。
对于包内已确认的CSV，仅在派生时间戳中应用2023→2017的作者确认修正，原CSV不变。新CSV默认使用原年份，可在有依据时显式传入--year。

三、验证方法
保持原始记录时间顺序：前268/336条原始记录为训练时段，后68条为测试时段。统一筛选具备连续24小时历史的目标后，共222条训练目标、68条测试目标。所有模型用同一组目标时刻和五折索引。
五折训练目标数为37、74、111、148、185，每折验证37条；gap=0。存在缺测，等记录数不等于等日历跨度。候选配置以训练期五折平均验证MSE选择，不按测试结果选择。OLS与LSTM均只有一个固定配置，不宣称进行了多参数搜索。确定配置后，用全部训练目标重新拟合，再评价末段测试。
LSTM只在每折训练信息上拟合X和y缩放器；输入为X_(t-23)…X_t，目标y_t，包含当小时输入。因此这是后续时段的同小时回归，不是提前24小时预报。训练序列批次可以打乱，窗口内部顺序与时间切分不打乱。固定50轮，没有使用最终测试期早停。
该数据的留出时段此前已用于15变量比较，属于共同参考测试时段，不是新增外部验证集。

四、环境与最简运行
推荐Python 3.12。先在独立虚拟环境安装依赖。
完整六模型环境：python -m pip install -r requirements_lstm.txt
仅表格模型与解释：python -m pip install -r requirements.txt
所有命令中的python均指安装了依赖的解释器。文件路径以脚本所在位置为基准，不需要修改Windows绝对路径。可在本目录执行下列命令。

只检查，不训练真实模型：
python self_check.py
python run_all.py --stage check

单独准备数据、训练和解释出行终点GE：
python prepare_data.py
python train_xgboost.py --targets EGE
python shap_analysis.py --targets EGE
python shap_dependence.py --targets EGE
python pdp_1d.py --targets EGE
python pdp_2d.py --targets EGE

独立训练其他模型：
python train_ols.py
python train_rf.py
python train_catboost.py
python train_lightgbm.py
python train_lstm.py

完整运行六模型、解释和图表（此命令会实际训练，解释默认使用XGBoost）：
python run_all.py --stage all

分阶段运行：
python run_all.py --stage prepare
python run_all.py --stage fit
python run_all.py --stage summary
python run_all.py --stage explain
python run_all.py --stage plots

--results可指定另一结果目录，--data可指定另一CSV。所有后续脚本的--results必须一致。例如：
python prepare_data.py --data data/GE.csv --results my_results
python train_xgboost.py --results my_results --targets EGE
python shap_analysis.py --results my_results --targets EGE

五、复用此前结果，不重新训练
prepare_data.py生成同一协议后，可导入此前13变量结果目录：
python import_saved_results.py --source-results /path/to/paper5_no_mobility
然后运行shap_analysis.py、shap_dependence.py、pdp_1d.py、pdp_2d.py、summarize_results.py或plot_predictions.py。
导入会核对原始数据指纹、13个变量、时间戳、训练/测试与五折索引，并验证表格模型能复现其保存的预测；不调用fit。

六、解释范围与绘图设置
SHAP/PDP默认解释原网格的XGBoost模型，也支持--model OLS、RF、CatBoost、LightGBM及显式生成的XGBoost_extended。LSTM为24×13序列模型，本包解释脚本面向OLS和树模型；不会将表格TreeExplainer直接套到LSTM上。
XGBoost和LightGBM采用全部训练背景的interventional TreeSHAP；OLS采用LinearExplainer；RF和CatBoost采用兼容其已保存模型的路径依赖TreeSHAP，使用训练树中的路径覆盖信息，不显式传入背景矩阵。全部模式均解释所有训练目标，并在元数据中记录方法和背景设置。每次均独立检查expected value + SHAP贡献之和能复现原生模型predict输出。不同解释假设的归因不能不加说明地比较。
SHAP总结图展示所有13个变量。SHAP依赖图和一维PDP默认展示训练排序前6个，可用--top-n 13分页展示全部，或用--features指定白名单中的特征（含空格的名称需加引号）。
PDP连续变量默认使用训练期5%—95%分位范围内31个网格值；若不同观测值不足31个，使用实际不同值。星期和小时使用实际整数编码。星期作为类别格展示，二维图不在星期编码间画连续等高线。小时仍使用原有整数编码，没有新增正弦/余弦特征。
二维PDP每一格都在全部训练背景上替换两个变量，再计算平均预测。9个面板共用按真实预测最小/最大值确定的数值色标。--contours可选叠加无文字等高线。PDP表示平均模型预测，SHAP依赖图表示归因，二者不混用。
原始代码中的普通独立重采样bootstrap置信带已移除；没有把不对齐的重采样曲线拼成置信区间。默认不估计平滑线、置信区间、显著交互或因果效应。相关变量的PDP组合可能缺少实际观测支持。
图输出为600 dpi PNG及带可编辑文字的PDF/SVG；运行时进行面板对齐、字体及文字重叠检查。新数据若触发重叠检查，需要调整布局后再使用该图。

七、结果与追踪
results/protocol.json：共同输入、时间索引、数据指纹。
results/models/：各目标、各模型的已拟合文件及元数据。
results/training/模型/目标/：候选列表、逐折分数、逐行预测、训练/测试指标。
results/explanations/模型/目标/：训练SHAP、排名、SHAP依赖图、一维和二维PDP数值及图形。
results/summary/：全部精度、六模型主比较、逐行预测及核验记录。
results/figures/：六模型共享坐标预测图。
代码只按真实结果报告排名，保留负R²，不修改指标以使任何模型获胜。扩展XGBoost搜索仅在train_xgboost.py --extended-search时启用，另命名保存，默认不替代主模型。
